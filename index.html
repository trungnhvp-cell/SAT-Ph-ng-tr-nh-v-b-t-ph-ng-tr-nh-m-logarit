I Phương trình mũ cơ bản (Basic Exponential Equations)

Tiếng ViệtEnglish
Phương trình \(a^x = b\) với \(a>0, a\neq 1\): nếu \(b>0\) có nghiệm \(x = \log_a b\); nếu \(b \leq 0\) thì vô nghiệm.\(a^x = b\) (\(a>0, a\neq 1\)): if \(b>0\), solution \(x = \log_a b\); if \(b \leq 0\), no solution.
Cùng cơ số: \(a^{f(x)} = a^{g(x)} \iff f(x) = g(x)\).Same base: \(a^{f(x)} = a^{g(x)} \iff f(x) = g(x)\).
Đặt ẩn phụ: \(t = a^{f(x)} > 0\), đưa về phương trình đại số theo \(t\).Substitution: let \(t = a^{f(x)} > 0\), reduce to algebraic equation in \(t\).
Ví dụ: \(2^{x} = 8 \iff x = \log_2 8 = 3\). · \(3^{2x-1} = 27 \iff 2x-1=3 \iff x=2\).

II Bất phương trình mũ (Exponential Inequalities)

Cùng cơ số: \(a^{f(x)} > a^{g(x)}\)
Nếu \(a > 1\): \(f(x) > g(x)\). Nếu \(0 < a < 1\): \(f(x) < g(x)\).
Dạng \(a^x > b\): nếu \(a>1\) thì \(x > \log_a b\); nếu \(00\)).
Dạng \(a^x < b\): nếu \(a>1\) thì \(x < \log_a b\); nếu \(0 \log_a b\).
Lưu ý: Nếu \(b \leq 0\): \(a^x > b\) luôn đúng ∀x; \(a^x < b\) vô nghiệm.

III Phương trình logarit (Logarithmic Equations)

Điều kiện: \(f(x)>0\), \(0
Cơ bản: \(\log_a x = b \iff x = a^b\).
Cùng cơ số: \(\log_a f(x) = \log_a g(x) \iff f(x) = g(x) > 0\).
Mũ hóa: \(a^{\log_a f(x)} = f(x)\) với \(f(x)>0\).
Đặt ẩn phụ: \(t = \log_a x\), giải phương trình theo \(t\).
Kiểm tra nghiệm ngoại lai (extraneous solution) — luôn thử lại với điều kiện.

IV Bất phương trình logarit (Logarithmic Inequalities)

Cùng cơ số: \(\log_a f(x) > \log_a g(x)\)
Nếu \(a > 1\): \(f(x) > g(x) > 0\). Nếu \(0 < a < 1\): \(0 < f(x) < g(x)\).

Dạng \(\log_a x < b\): nếu \(a>1\) thì \(0 < x < a^b\); nếu \(0 a^b\).

V Hệ phương trình mũ – logarit (Systems)

  • Phương pháp thế: biểu diễn một ẩn theo ẩn kia.
  • Cộng đại số: kết hợp hai phương trình để triệt tiêu.
  • Đặt ẩn phụ: đưa hệ về hệ đại số cơ bản.
  • Dùng tính đơn điệu: hàm số mũ/logarit đơn điệu → phương trình có tối đa 1 nghiệm.
Ví dụ: \(\begin{cases}2^x \cdot 2^y = 8\\ x + y = 3\end{cases}\) → \(2^{x+y}=8\) thỏa mãn, vô số nghiệm dạng \(y=3-x\).

VI Ứng dụng thực tế (Real-World Applications)

Lãi kép: \(A = P\left(1+\dfrac{r}{n}\right)^{nt}\) · liên tục: \(A = Pe^{rt}\).
Tăng trưởng/suy giảm: \(N(t) = N_0 e^{kt}\) (\(k>0\): tăng, \(k<0\): giảm).
Chu kỳ bán rã: \(N(t) = N_0\left(\dfrac{1}{2}\right)^{t/T}\), \(T\) = half-life.
Thời gian nhân đôi: \(t = \dfrac{\ln 2}{r}\) (tăng trưởng liên tục).
pH: \(\text{pH} = -\log[\text{H}^+]\) · Richter: \(M = \log\dfrac{I}{I_0}\) · Decibel: \(L = 10\log\dfrac{I}{I_0}\).
